# 无名杀自制武将扩展

本仓库收录五套玩家自制的无名杀扩展：**屈原、武段颎、隐蕃、翰墨凝威、李牧**。翰墨凝威目前包含威曹丕、威曹植、威曹操，以及十位作者的完整70篇华章。

技能与武将设计由 **辟境归元（GitHub：[@120mousimashi](https://github.com/120mousimashi)）** 完成；代码实现、调试与打包由 **OpenAI Codex（GPT）** 协助完成；武将原画由 **GPT 生成**。本项目为玩家自制扩展，并非官方产品。

## 安装和导入

1. 下载需要的**单个扩展 ZIP**，不要解压后再选里面的文件。
2. 在无名杀的扩展管理界面选择导入扩展或导入压缩包，选中下载的 ZIP 并确认。
3. 导入后检查对应扩展已启用；完全退出并重新启动游戏，再选择武将。

直接导入时，游戏会读取压缩包中的扩展名称，**无需提前在编辑器里新建扩展，也无需手动添加“自制”**。导入同名扩展可能替换原有内容，如有自行修改的同名版本，请先备份。

如果确实使用编辑器或手动复制目录，请按上表准确使用扩展名：屈原为“自制屈原”，武段颎为“自制武段颎”，隐蕃、翰墨凝威、李牧不加“自制”。扩展名与图片路径相对应；随意更名而不调整资源路径可能导致立绘不显示。**武将显示名仍分别是“屈原”和“武段颎”。**

五套扩展针对无名杀 **1.11.6 单机**制作，设计者反馈测试时未发现问题。其他游戏版本、其他扩展组合与联机兼容性尚未全面验证。

“华章”是翰墨凝威的专属机制，以历史文人真实作品命名。书写时从当前可获得的剩余篇目中随机抽至多三篇并选择一篇；有可获得的自作时至少包含一篇自作。每篇全场同时只能存在一份。自作通常不限，普通外来华章最多三篇；威曹操的建安生效时可以突破外来上限。华章通常要等效果及其延时部分完整结算后才回库，特殊例外和阵亡继承见规则文档。
