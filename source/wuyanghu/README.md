# 武羊祜

无名杀 1.11.6 单机测试扩展，版本 0.1.0。

## 武将信息

武羊祜，群势力，男，体力 3，体力上限 3。

技能设计：辟境归元。代码实现与打包：OpenAI Codex 协助。原画由设计者提供；本包仅转换图片格式，不裁切或重绘。

## 导入

在无名杀扩展菜单中选择导入扩展，选择本 ZIP。导入后手动开启“武羊祜”并重启游戏，在武将包中启用本扩展。

无需新建扩展，也不要更改扩展名或图片文件名。立绘路径为 `ext:武羊祜/bjgy_wuyanghu.jpg`。若之前在编辑器粘贴过相同 ID 的测试技能，请先删除重复定义，避免加载旧代码。

## 技能

**德信**：出牌阶段限一次，你可以交给一名其他角色或令一名其他角色交给你一张牌，若给牌的人给出的是伤害牌，则其弃置当前体力值张手牌然后视为对获得牌的角色使用一张与给出的牌牌名相同的伤害牌且此牌造成伤害时伤害+1，然后伤害来源失去一点体力，若给出的是非伤害牌，你们各摸两张牌且你额外获得两张点数为J的牌，然后该技能本阶段改为出牌阶段限两次。

**煌势**：锁定技，每名角色的出牌阶段开始时，你将至多1张手牌明置；你使用点数为J的牌指定其他角色为目标时，此牌额外结算X次；你使用J点牌拼点时本次拼点结果视为所有角色平局（X为你明置的手牌数且至多为3）；你手中明置的手牌点数视为J。

**明贤**：限定技，出牌阶段，你可以令自己的手牌本阶段始终明置，且使用黑色牌指定其他角色为目标时，若目标角色手牌数大于你，你弃置其一张牌。

## 已确认的结算

- 德信给牌范围为手牌和装备区，给牌者自己选择。伤害分支弃手牌不足时弃光后继续，虚拟牌无距离和次数限制且不计次，保留杀的属性但不继承给出牌的花色和点数。
- 德信每次实际伤害加一，然后由该次真实伤害来源失去一点体力；决斗反伤、连环传导与额外结算均适用，未造成伤害不支付代价。
- 非伤害分支获得两张 J，先从牌堆随机检索，不足再检索弃牌堆。本阶段限两次包含已发动的次数，不累加到三次以上；额外出牌阶段重新计算。
- 煌势逐张明置持续到牌离开手牌。所有来源的明置手牌均视为 J；用牌时保留离手前有效点数，指定目标时取剩余明置手牌数作为 X。
- 煌势为整张牌增加 X 次结算，所有原目标共同参与；不重复指定目标。J 拼点使整次多人比较的所有角色平局。
- 明贤仅持续当前实际出牌阶段，期间新获得的手牌也明置。阶段结束仅移除明贤来源，保留煌势及其他来源的明置。黑牌逐个原始目标检查手牌数并弃置其手牌或装备牌。
