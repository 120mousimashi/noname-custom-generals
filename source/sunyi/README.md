# 孙伊

无名杀1.11.6单机测试扩展，版本0.1.0。吴势力，女性，初始体力4，体力上限4。

技能设计：辟境归元。代码实现与打包：OpenAI Codex协助。原画由设计者提供，使用本次提供的孙伊.png；仅转换为真正JPEG，不裁切、缩放或重绘。

## 导入

在无名杀扩展菜单选择导入扩展，选择本ZIP。导入后手动开启“孙伊”并重启游戏，在武将包中启用本扩展。

无需新建扩展。扩展名为“孙伊”，立绘路径为 `ext:孙伊/bjgy_sunyi.jpg`。若编辑器里已有相同ID的旧测试技能，请先删除旧定义，避免加载重复代码。

## 技能

**占卦**：每回合开始时，当前回合角色可以交给你一张手牌，然后你可以进行一次判定，若判定牌为：1.红色：你与该角色各摸两张牌；2.黑色：你与该角色各对一名其他角色造成一点伤害。你进行判定时，可以弃置一张手牌，根据此牌和判定牌的颜色组合执行以下效果：1.红色黑色：摸一张牌并获得判定牌，且本次判定结果以你弃置的牌为准；2.红色红色：视为使用一张基本牌；3.黑色红色：弃置一名其他角色两张牌，且本次判定结果以你弃置的牌为准；4.黑色黑色：视为使用一张普通锦囊牌（每轮每种牌名限一次）。

**绍翊**：出牌阶段限一次，你可以将至少X张牌当做一张不计次的“杀”使用，若转化的牌中每种颜色的牌数量：1.不一样：你失去一点体力然后进行一次判定，若判定颜色为其中较多的颜色，该技能本阶段可使用次数+1，且你使用的下一张“杀”伤害+X；2.一样：你回复一点体力然后进行一次判定，若判定结果为伤害牌，该技能本阶段可使用次数+1，且你使用的下一张“杀”造成伤害后摸两张牌（X为该技能本阶段的发动次数）。

## 定稿结算说明

### 占卦

- 每个实际回合开始时询问当前回合角色，只有成功交出一张手牌才进入孙伊的判定选择；孙伊可以收牌后拒绝判定，不退还已给的牌。
- 允许孙伊在自己回合交给自己，手牌不丢失、不复制。红色依次摸两张、再摸两张，共四张；黑色依次选目标两次，分别造成一点伤害。
- 黑色结果由两名角色各自选择相对于自身的其他角色，可以互相选择，也可以都选择同一名第三人。孙伊先执行，再由当前回合角色执行；每次重新检查在场状态。
- 后半段适用于孙伊的全部判定，包括占卦、绍翊、延时锦囊等。判定牌亮出后、生效前，可以弃置一张可弃手牌，每次判定至多发动一次。
- 颜色组合按“所弃手牌在前、当前判定牌在后”。红黑/黑红改变的是完整判定牌信息，包括牌名、花色、点数、颜色，仍能被后续正常改判覆盖。
- 红黑先摸一张，再获得被换下的原判定牌；黑红由孙伊选择其他角色的两张手牌或装备牌弃置，不足则弃置能弃的牌，原判定牌正常弃置。
- 若所弃牌已被弃牌联动取得，仍以其完整判定快照为准，不抢回或复制该实体。原判定牌已被其他效果取得时，不重复获得。后续鬼才、鬼道仍可正常改判。
- 红红视为使用一张当前合法的基本牌，黑黑视为使用一张当前合法的普通锦囊，均按正常距离、次数与目标限制处理，无合法选项则无事。黑黑的每轮每牌名一次只约束本项，成功使用才消耗，下一轮恢复。

### 绍翊

- 转化素材来自手牌和装备区，至少X张，转化为普通杀。无次数限制且不计次，距离限制照常；不是打出技能。
- 每个实际出牌阶段初始总额度为一次，实际发动的X从1累计递增。成功判定只增加本阶段可使用次数，不清零X。因此第二次至少两张，第三次至少三张。
- 素材颜色在使用前确定，只比较红牌数和黑牌数，缺少的一种按0计算；无色素材不计入任一颜色，但仍计入素材张数。例如三红零黑为不一样，两红两黑为一样。
- 本次转化杀完整结算后，才失去/回复体力及判定。失去体力进入濒死后获救会继续，阵亡则中止后续；满血回复不到体力也继续判定。
- 以最终实际判定结果的颜色和牌名判断，包含占卦及其他改判的结果。判定中占卦印出的牌早于本次奖励，不会提前享受尚未获得的强化。
- 两种“下一张杀”效果可以共存，同种加伤数相加、摸牌层数累计，跨阶段及回合保留。下一次成功使用杀时消耗，即使该杀没有造成伤害也消耗；打出杀不消耗。
- 加伤提高该杀整张牌的基础伤害，对其全部目标生效，连环传导继承原伤害。摸牌按这张杀每次实际造成伤害事件结算，每层摸两张，一次多点伤害仍只触发一次；独立技能直伤和虚假伤害不冒领。
- 取消或未真正使用不占本阶段发动次数；已获得的强化在失去主技能后仍能完成，结算中新取得的强化留给之后的杀。
