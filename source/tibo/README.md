# Tibo v0.1.0 测试版

无名杀1.11.6单机武将扩展，群势力、男性、体力/体力上限3/3。武将与扩展名称均为Tibo。

技能设计：辟境归元。代码实现、调试与打包：OpenAI Codex（GPT）协助。原画：设计者提供的GPT生成图。武将数值按设计文档登记，所给原画保持原始内容。

## 导入

在扩展管理中直接导入本ZIP，手动开启“Tibo”，完全退出并重启游戏，再新开一局。无需在编辑器中新建或改名。若其他测试扩展已登记同ID武将或技能，请停用重复定义。本包不依赖其他第三方扩展。

## 复额

每轮限一次，一名角色的回合结束时，你可以令该角色执行一个完整额外回合。该额外回合完结后，该角色须跳过其下一个回合，包含其他技能给予的额外回合。

- 可以对自己发动。额外回合在当前回合结束相关触发处理后插入，不因本次插入而刷新复额每轮限次。
- 给予的额外回合即使因翻面或其他效果被直接跳过，仍产生跳下一回合的代价。
- 偿还时若背面朝上，先依本体规则翻回正面并跳过该次机会，此次不消耗复额代价；等下一次本可正常开始的回合再偿还。
- 跳回合代价按次数记录；已授予的代价不随Tibo失去复额或阵亡而取消。

## 挑战

锁定技，本局游戏你实际使用的前28张牌，每张先等概率随机抽取项目数1至6，再从六项中不重复抽出对应数量，按编号顺序在本张牌效果结算前执行：

1. 此牌无次数限制且不计入次数。使用前仍须满足当时正常用牌合法性，不能先超次数出牌再赌本项。
2. 随机从弃牌堆获得一张因你使用而进入过弃牌堆、且目前仍在弃牌堆的实体牌。包括转化使用的实体材料；仅认具体实体，不按同名检索其他人的牌。当前仍在处理区的本张牌不能提前获得；用过的装备后来才被其他角色弃置，不因此满足条件。
3. 本局游戏手牌上限+1，每次抽中均叠加。
4. 此牌不能被响应，包括普通响应和无懈可击。
5. 若本张牌名未记录，则记录。首次记录的当张牌不摸；以后每次使用此前已记录的牌名摸1张，第29张以后仍有效，不要求再次抽中本项。重复抽中本项不叠加每次摸牌数。
6. 随机从牌堆获得一张点数恰好比本牌大1的牌，K接A。仅处理A至K；无点数、0、超过K不检索，且不改从弃牌堆取牌。

用牌按实际使用事件计数：虚拟牌、无懈、回合外使用和不计次使用均计入；打出不计，多目标或同张牌额外结算不重复计次。杀及其属性版本共用“杀”牌名。第二、第六项没有符合牌时仍可被抽中，尽量执行后不补抽其他项目。已获得的本局手牌上限和牌名摸牌效果独立保留。
