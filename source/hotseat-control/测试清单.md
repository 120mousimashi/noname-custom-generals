# 全席接管 V0.1.2 客户端验收清单

已勾选项目仅表示2026-11-02在真实客户端乱斗四人预设或普通四人身份局中已完成的所列操作，具体过程见测试报告；未勾选项目仍待验收。60项自动验证通过不能代替实机检查。先用简单标准武将，再逐个加入自制武将；普通身份局或乱斗身份场景均须符合README的实际四席、单武将等范围。

## 基础验收

- [ ] 导入、启用并重启后，扩展列表名称为“全席接管”，没有新增测试武将。
- [x] 进入乱斗后能找到“全席接管·四人测试”预设。
- [ ] 其他已有场景及手动修改的同名场景仍保持原样。
- [x] 新版安装并重载后，开局前左上横向显示“全席接管已加载 · 等待四人身份局开局”，开始预设后变为“全席手动”。
- [x] 普通四人标准身份局在本体原生选将完成后能够启用接管，不需要创建乱斗场景：原本人控反贼张恭取消手气卡后，界面切到主公钟会出牌窗口，等待人工。
- [x] 普通身份局中主公钟会的黑桃2雌雄双股剑可由人工点牌、确认使用，手牌由6张减至5张，装备区出现该剑，仍停在钟会出牌窗口等待人工。
- [ ] 普通四人身份局四席完整轮转一整轮并正常终局（本次仅实测启动及主公装备出牌）。
- [x] “全席接管·四人测试”预设能正常进入对局、发出初始手牌；面板显示“全席手动”。
- [ ] 实际四席、单武将的正常身份场景不会仅因不是主忠反内各一名或不是预设座位而被拒绝；身份、座位保持原样。
- [x] 四席完成一整轮各自回合：曹操使用南蛮并结束、弃牌，刘备用杀并结束，孙权手动结束、选弃牌，华佗手动使用装备、结束并弃牌；这些动作均由人工选择与确认，之后进入第2轮曹操出牌阶段，无报错或暂停。
- [x] 曹操使用南蛮后，刘备、孙权分别手动点杀并确认，手牌各由4张减至3张；华佗取消响应后受伤，结算返回曹操出牌阶段。
- [x] 刘备手动选杀、指定曹操并确认，切到曹操手动出闪；曹操手牌由4张减至3张且未受伤，之后返回刘备出牌阶段。
- [x] 孙权可手动结束出牌并选择弃置1张牌；华佗手动使用八卦阵后手牌由6张减至5张，装备区出现八卦阵。
- [x] 华佗结束出牌后手动逐张选满3张弃牌并确认，手牌由5张减至2张，之后进入第2轮曹操回合。
- [x] 本次十周年UI环境中，杀、闪响应没有被自动预选，需人工点牌并确认。
- [ ] 决斗双方有杀时轮流询问；一方取消后，由正确角色受伤。
- [ ] 普通锦囊和延时锦囊均能询问四席中有合法无懈能力的角色；无懈链结束后原牌按结果结算。
- [ ] 交换、获得、弃置其他角色的牌时，操作角色和被选牌的区域正确。
- [ ] 两人及多人拼点均逐个选各自的牌，没有一方被AI代选。
- [ ] 可取消的频繁技既能选择发动，也能选择不发动。
- [ ] 濒死时依次询问救援者，桃或技能材料由实际救援者支付。
- [ ] 嵌套技能让另一角色选牌后，返回原选择者，继续选牌或目标正常。
- [ ] 观牌、整理牌堆顶底的界面可以人工移动牌并确认，没有丢失实体牌。
- [ ] 托管及自动拒绝无懈按钮、W键不会启用自动操作。
- [ ] 击杀反贼的牌由实际来源获得；主公杀忠臣的惩罚落在主公身上。
- [ ] 主公死亡等原生条件正常终局，结果依据接管启动时原本控制的席位，最后操作谁不影响参考席。
- [ ] 导出记录能得到JSON文件，事件与当前角色可读。
- [ ] 关闭扩展并重启后，普通游戏和原有自动偏好正常恢复。
- [ ] 实机停止接管后，十周年UI自动选牌设置正确恢复（自动回归已覆盖，客户端尚未实测）。

## 自制技能组合复测

这些组合用于发现真实扩展中的接口差异，未在本版自动验证中逐个跑完整局。

- [ ] 郭脩“趋贺”的其他角色代理响应：依次询问、正确付款并返回原结算。
- [ ] 郭脩“孤刃”及死亡后续：阵亡、失去体力、技能移除和势力变更归属正确。
- [ ] 郑以“守藏”的阵亡遗传询问仍由玩家决定，死者不因无法选择而卡住。
- [ ] 诸葛仪“承图”、钟忆“玄阵”的观牌排序可人工完成，返回后继续操作者正确。
- [ ] 翰墨凝威的华章候选、传承及延时效果中的嵌套选择可依次人工操作。
- [ ] 辅翼谙计中的额外阶段、额外回合、跳过阶段后，下一次选择仍切到实际决策者。

## 范围及暂停检查

- [ ] 联机、录像、非normal身份、非四席、副将、年机制或场景回合数／洗牌次数强制胜负条件会被拒绝；面板说明原因，不冒充已接管。
- [ ] 未完成选将或使用未加载武将时不会误启用。
- [x] 已正常完成本体选将的四人普通身份局不会被旧场景白名单拦截。
- [ ] 已识别的狂乱、强制计时或自建代选界面冲突会明确暂停，确认错误框后不会自动续跑该选择。
- [ ] 若出现没有暂停却自动作答、手牌面板错席、牌消耗错人或原选择丢失，立即导出记录并停止该局，保留复现步骤。

反馈时最好先写“通过了哪些步骤，第几项失败”，再附截图与记录。这样可以区分场景配置问题、接管入口遗漏和武将技能自身错误。
