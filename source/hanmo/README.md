# 翰墨凝威 1.2.0 建安更新测试版

作者：辟境归元。适用无名杀1.11.6单机。文人之威：威曹丕、威曹植、威曹操，以及十位作者的70篇完整华章。

## 导入

在无名杀扩展导入界面选择整个“翰墨凝威_v1.2.0_建安更新测试版.zip”，覆盖同名扩展，确认启用后完全退出并重启，再新开一局。扩展名保持“翰墨凝威”；无需另装威曹植包。若曾在另一个自制扩展中手动添加同名技能，仅清除那些重复技能后再试。

正式角色为魏、男、4体力的威曹丕〖评文〗〖品藻〗、魏、男、3体力的威曹植〖高才〗〖华藻〗、魏、男、4体力的威曹操〖横槊〗〖建安〗，均使用用户提供的正式原画。

本版已移除所有测试身份、测试面板及直接书写/指定获得/传递的调试技能。通过评文、华藻或建安正常书写华章，持有主动华章时使用〖华章〗入口；琴歌、隐士、愍骥等仍在对应原生用牌界面发动。阵亡继承继续按华章规则结算。

## 威曹植

高才每次使用牌都记录一次牌名，相同牌名可重复，记录跨回合保留。总字数达到或超过8时，先清空，再摸两张牌，不保留溢出。虚拟使用也计入，打出不计。

华藻出牌阶段限一次，可弃至少一张手牌，所选牌名字数排序后须成等差数列，公差可为0。先弃牌并摸等量，再按实际弃牌的类型数依次书写、视为使用普通锦囊、刷新发动次数。类别为基本、锦囊、装备；锦囊限名只记录本回合通过华藻使用的牌名。合法锦囊必须选，无合法选项则跳过；书写失败不妨碍后续。三类刷新不重置本回合锦囊牌名限制。

完整技能与华章正文、已确认细节见《华章库70篇.md》《结算规则.md》。

## 威曹操

横槊出牌阶段限三次，可分别与可拼点的其他角色拼点。相关触发全部结算后，由曹操决定是否令赢家按当前手牌数执行效果：大于其体力值，使用不计次的酒；等于，赢家选一至两名合法目标使用决斗；小于，赢家选择一种合法的杀，无距离限制但仍受杀次数限制，实际使用时立即将手牌摸至体力上限，再继续杀的结算。平局没有赢家效果；不能使用杀就不补牌。

建安：锁定技，你参与的拼点改为比较牌名字数；本次拼点每有一名其他角色没赢，你书写一篇华章并摸一张牌。双人曹操赢或平都奖励一份，曹操输不奖励；一对多逐组结算自己参与的组；共同拼点只认唯一最高，最高并列无人赢，每名其他未赢者各奖励一份。字数只替换本次比较值，不改变实体牌点数；点数增减不成为字数加成，直接判赢效果保留。每份先书写再摸1，空库仍摸1。新增摸牌也在横槊判断当前手牌前结算。建安生效时外来华章无数量上限；失效后保留已有华章，新增按通常三篇上限，恢复后重新不限。不限量不改变全场唯一、随机三选一、自作保底，也不作为篇目永久免额传给普通接收者。
