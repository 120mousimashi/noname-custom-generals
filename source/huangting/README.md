# 皇庭

这是无名杀「皇庭」系列的整合扩展，包含十二名武将。

- 魏势力：J张辽、Q郭照、K曹丕
- 蜀势力：J关羽、Q吴苋、K刘备
- 吴势力：J陆逊、Q潘淑、K孙权
- 晋势力：J羊祜、Q杨艳、K司马炎

K孙权使用统衡两项弃牌均计入效果的 v0.1.1 版本。武将技能、立绘及各自对应的扑克牌效果见游戏内武将和牌面说明。

导入整个「皇庭.zip」，在扩展菜单启用「皇庭」，完全退出游戏后重新启动。若已安装这些武将的单独扩展，请先停用单独扩展，避免重复的同名技能和皇庭规则同时加载。本包针对无名杀 1.11.6 单机测试。

皇庭是公共机制。系列武将登场时，牌堆中对应花色点数的牌被替换成扑克牌。初始手牌流程完成后，对应武将获得这些牌。每回合结束后，弃牌堆里的扑克牌随机分给存活角色。扑克牌的具体持有、失去和身份效果见对应牌面说明。
