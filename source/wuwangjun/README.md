# 武王濬

v0.1.0 测试版，适配无名杀1.11.6。群势力，男性，初始体力4，体力上限4。

技能设计：辟境归元。代码实现、验证和打包：OpenAI Codex协助。原画由设计者提供，本包仅将PNG转换为JPEG，保持尺寸，不裁切、不重绘。

## 导入

1. 在无名杀扩展管理中选择导入扩展，直接选择本ZIP，无需解压或先新建扩展。
2. 手动开启“武王濬”，重启游戏，再开新对局测试。
3. 扩展名与原画目录统一为“武王濬”，不要额外添加“自制”等前缀。
4. 若编辑器里已有相同内部ID的测试技能，请移除旧副本后再测试，避免重名冲突。

ZIP根目录包含extension.js、info.json、bjgy_wuwangjun.jpg、README.md、LICENSE。没有内层压缩包，没有语音文件。

## 技能

**下江**：每回合每种牌名限一次，你可以将1或2张手牌当做任意基本牌或普通锦囊牌使用，以此法使用的牌点数视为素材牌点数之和。若此点数不为10，该技能本回合失效。

**全瓯**：锁定技，你使用点数为10的牌指定目标时，令其中一个不为你的目标角色选择一项：1.交给你X张牌；2.令其下一次受到的属性伤害＋X，然后横置其武将牌（X为该选项本回合被选择的次数，包含本次选择）。有角色被横置时，根据此时场上势力数依次执行所有符合条件的效果：不大于1，你对其造成1点火焰伤害；不大于2，本局游戏你摸牌阶段摸牌数和出牌阶段使用杀的次数＋1；不大于3，你重铸任意张牌，然后获得本次重铸牌点数之和除以10向下取整数量张点数为10的牌；不大于4，你摸一张牌且本局游戏手牌上限＋1。

**驱贤**：限定技，出牌阶段，你可以令场上所有其他角色的势力修改为和你相同直到本回合结束，然后你获得本次势力变动的角色各一张手牌，本回合你使用这些牌无距离和次数限制。

## 结算说明

- 下江仅支持使用，不支持决斗中单纯打出杀。需要使用闪、救援用桃或无懈可击时，仍须满足对应使用条件。普通杀、火杀和雷杀共用“杀”的牌名次数；普通方式使用同名牌不占下江额度。
- 取消下江选择不消耗机会；确定用牌时记录该牌名。素材点数在离手前确定，包括点数修改效果。两张4与6转化出的牌点数为10，可以触发全瓯。合计不是10时，本次牌仍正常使用，随后本回合下江失效。
- 全瓯每张10点牌仅选择一名其他目标执行一次。两个选项独立计数、不同目标共用持有人的本回合计数，先计入本次再算X。依次选①②①时，X为1、1、2。
- 交牌由目标从手牌和装备中自行选足X张，不足时不能选择交牌。属性易伤先附加再横置，故一势力时全瓯自己造成的火焰伤害会受到这次加成。
- 已横置的角色仍可选择第二项获得易伤，但不会再次发生横置。重复获得的易伤相加，下一次属性伤害一起结算；回合结束、普通伤害、解除横置均不清除等待中的易伤。伤害被防止或降至0时，预占的易伤返还，与期间新获得的层数相加。
- 全瓯后段包含任何来源使任何角色从未横置变成横置，包括武王濬自己；解除横置不触发。多人横置分别结算。每次按当时存活角色的势力种类数确定本次档位。
- 四档累计执行：一势力执行全部四项，两势力执行后三项，三势力执行后两项，四势力只执行摸牌加手牌上限，五势力及以上无后段效果。永久收益可以累加。
- 重铸选择手牌或装备，可选0张；只统计本次实际重铸的牌，点数总和27获得2张、123获得12张。检索10点牌先从牌堆随机获取，不足再从弃牌堆找，仍不足则取得现有数量，不凭空生成。
- 驱贤先改变所有符合条件角色的势力，再逐人获得手牌。原本同势力者不算势力变动，不提供手牌；变动者没有手牌则略过取牌。改变势力本身不触发全瓯，之后横置才按变化后的势力数结算。
- 驱贤取得的指定实体牌，本回合由武王濬使用时无距离和次数限制，同时不计次；包含以这些牌作为素材的转化用牌，不绕过禁止使用等限制，不给其他持有人相同收益。回合结束恢复原势力并结束牌的使用收益，清理不依赖驱贤仍有效。

## 建议测试

测试4＋6下江、非10点后的封锁与下一回合恢复、下江无懈窗口；同张多目标牌全瓯只选一次、两选项分别累积；已横置时叠易伤与一势力即时火伤；重铸检索；驱贤后全部势力统一、原同势力不取牌及回合结束还原。
