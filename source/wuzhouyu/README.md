# 武周瑜 v0.1.0 测试版

武将：武周瑜；势力：吴；性别：男；体力：4/4。

技能设计：辟境归元。代码实现与打包：OpenAI Codex协助。原画：设计者提供，GPT生成。

面向无名杀1.11.6单机测试。使用本体接口实现，无需千幻聆音或皮肤切换。暂未宣称联机或录像兼容。

## 导入

1. 在无名杀扩展管理中导入本ZIP，直接选择压缩包即可。
2. 扩展名称是“武周瑜”，导入后手动开启该扩展并重启游戏，重新开始一局。
3. 在武将包中启用“武周瑜”，选择武周瑜测试。
4. 如果以前在编辑器另建过同技能测试角色，请先停用该旧扩展，避免重复测试代码干扰。

ZIP根目录直接包含extension.js、info.json、bjgy_wuzhouyu.jpg、本说明和LICENSE。角色ID为bjgy_wuzhouyu，原画路径为ext:武周瑜/bjgy_wuzhouyu.jpg，扩展名称、路径保持一致。

## 技能

**顾曲**：你使用装备牌结算完成后，你可以展示一名攻击范围内或攻击范围内没有你的其他角色的一张手牌，若此牌与你本次使用的装备牌花色：1.相同：你对其造成一点火焰伤害；2.不同：弃置此牌。

**筹炬**：每轮限一次，一名角色的出牌阶段结束时，若本阶段场上现存的每个势力都有角色成为过牌的目标，你可以令一名其他角色本轮视为在所有角色的攻击范围内，且所有角色对其使用牌无距离和次数限制，然后你摸场上势力数张牌。若本阶段有角色造成过火焰伤害，你再获得场上势力数张点数为5的牌；然后你执行一个出牌阶段，你于此阶段造成火焰伤害后，摸一张牌；你击杀一名角色后该技能视为未发动过。

**雄贤**：限定技，出牌阶段，你可以令本回合所有手牌被展示过的角色始终横置直到本回合结束，且本回合处于横置状态的角色须始终将手牌明置，然后选择一项：1.修改“顾曲”；2.修改“筹炬”；3.获得牌堆、弃牌堆、场上、其他角色手中的所有点数为5的牌。

**顾曲（改）**：你使用装备牌结算完成后，你可以展示任意名被横置的其他角色和一名攻击范围内或攻击范围内没有你的其他角色的一张手牌，若本回合你：1.使用过该花色的装备牌：你弃置此牌并对其造成一点火焰伤害；2.没有使用过该花色的装备牌：获得此牌。

**筹炬（改）**：每轮限一次，一名角色的出牌阶段结束时，你可以令一名其他角色本轮视为在所有角色的攻击范围内，且所有角色对其使用牌无距离和次数限制，然后你摸场上势力数张牌。若本阶段有角色造成过火焰伤害，你再获得场上势力数张点数为5的牌；然后你执行一个出牌阶段，你于此阶段造成火焰伤害后，摸一张牌，且本次受伤的角色本阶段不能响应你的牌；你击杀一名角色后该技能视为未发动过。

## 已确认的结算

- 原顾曲的范围满足其一即可：你能攻击目标，或目标不能攻击你。按装备使用完成时的当前攻击范围判断；由你选择目标的一张未知手牌，不能提前查看全部手牌。
- 改顾曲可任意选择横置的其他角色，再额外选择至多一名符合原范围者；可只选其中一类，至少一人，每人一张且不能重复。按座次逐人展示并结算。记录本实际回合全部用过的装备花色，包含本次装备。应弃置的牌受到保护或在展示后移走时，不取消独立的火焰伤害。
- 筹炬在阶段结束时确定存活在场角色的势力种类数，两次数量共用。势力覆盖记录目标成为目标时的势力，之后阵亡或更改势力不抹去；自己对自己使用装备、桃等也能留下记录，已指定后被抵消的牌亦可。
- 筹炬由周瑜摸牌。检索5点牌先随机检索牌堆，不够再找弃牌堆，仍不足就只获得实际找到的牌。
- 无次数限制同时不计次数。次数耗尽后只对筹炬目标放开限制，其他目标仍须满足本体合法性；包含筹炬目标的合法使用整张牌不计次数。真实攻击范围效果与用牌距离效果分别生效。
- 周瑜击杀任意角色即可刷新筹炬，可以在其给予的额外出牌阶段结束时再次发动。不同发动选中的角色可并存至本轮结束。额外阶段每次实际火伤事件摸一张，不按伤害点数计算；连环火伤按实际伤害来源计算。
- 改筹炬的响应封锁只存在于对应的额外阶段，针对周瑜在造成该次火伤后使用的后续牌，包含无懈可击、使用或打出响应牌；不追溯禁止首次火伤所属牌的既有结算。
- 雄贤横置名单在发动时确定；本回合展示过任意一张手牌就符合，不要求展示全部，不限展示来源，包含周瑜自己。之后新增的展示不再扩大本次锁定名单。
- 锁定者本回合不能解链，包含铁索连环及属性伤害的解除横置流程；属性传导仍按本体一次传导规则处理，不另造传导伤害。
- 雄贤发动后，本回合任何横置角色都持续明置手牌，包含后来横置者和新获得的手牌。回合末只解除限制与本技能添加的明置，不主动解除横置、不清除别的技能的明置。
- 两项修改均永久替换技能效果，技能面板随修改显示完整新版说明。雄贤第三项拿牌包含所有在场角色的装备区和判定区（包括自己），以及其他角色的手牌；不包含武将牌上、私人牌堆的牌。按发动取牌时当前点数冻结清单，批量移牌后一次获得，不附带“沉略”移出游戏的后续效果。
- 已施加的回合、轮次效果不因周瑜阵亡或失去原技能提前撤销；在对应实际回合或轮次结束时清理。

## 建议测试

先分别测试原顾曲同花色/异花色，再发动雄贤修改顾曲，确认新旧花色、多名横置目标的处理。筹炬测试势力覆盖不全与全覆盖、火伤检索、击杀后再次执行阶段。雄贤测试只展示过一张手牌的角色、铁索解链失败、火雷传导、新摸牌立即明置，以及回合结束释放限制。第三项测试自己装备、他人判定与手牌中的5点牌一并取得。
