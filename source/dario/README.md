# 达里奥 v0.1.0 测试版

无名杀1.11.6单机武将扩展。扩展名和武将名均为“达里奥”，群势力、男性、体力/体力上限4/4。

技能设计：辟境归元；代码实现、验证与打包：OpenAI Codex（GPT）协助；原画：设计者提供的GPT生成图。数值按设计文档，封号目标按会话最终确认限定其他角色。

## 导入

在游戏扩展管理中直接导入本ZIP，手动开启“达里奥”，完全退出并重启游戏，再新开一局。无需在武将编辑器中新建或改名。

ZIP根目录包含extension.js、info.json、bjgy_dario.jpg、README.md、LICENSE。立绘使用`ext:达里奥/bjgy_dario.jpg`，不依赖皮肤扩展。

## 封号

出牌阶段限一次，你可以选择一名没有封号效果的其他角色，令其获得由你选择的一项限制：

1. 不能使用手牌，包括以手牌为材料使用转化牌；允许打出手牌。因此可以打出杀响应决斗，但不能使用手牌中的闪、无懈可击或桃。无手牌材料的虚拟用牌、只使用装备区材料的转化牌仍可用。
2. 非锁定技失效，按本体常规封印判定处理。装备授予的技能、锁定技和charlotte独立机制保留，华章等独立机制不因该效果失效。

封号不能叠加、替换，无回合期限，不随达里奥失去技能或阵亡解除，只能通过申诉获胜解除。

## 申诉

锁定技，有封号效果的角色的回合开始时，其视为对你使用一张决斗。若这张决斗直接对你造成实际伤害，其封号效果消失；若直接对其造成实际伤害，你获得其X张手牌或装备牌，X为你与其因本次决斗成功打出杀的总数。

- 达里奥为决斗目标，先打出杀。纯虚拟决斗不受“不能使用手牌”限制；其他效果导致无法合法使用时本次不执行。
- 双方成功打出的杀均计数，两张材料转化一张杀算1，零材料杀算1。激将等完成的角色响应算1，不把第三人的代打再次计数。需要打两杀时，已经成功打出的第一张仍计入X。
- 只认本次决斗直接造成的实际正伤害，其他技能反伤、转移给其他角色的伤害、被防止的伤害或失去体力均不触发上述结果。
- 达里奥选择获得哪些牌；不足X张则全部获得，X为0不获得。判定区不在获得范围内。
- 申诉决斗直接导致达里奥阵亡，仍属于申诉获胜并解除对应封号；达里奥因其他原因阵亡不会解除已有封号。
