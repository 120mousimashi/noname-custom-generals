武将：武吕蒙；势力：吴；性别：男；初始体力：3；体力上限：6。

技能设计：辟境归元。代码实现与打包：OpenAI Codex协助。原画：设计者提供，GPT生成。

## 导入

1. 在无名杀扩展管理中直接导入本ZIP。
2. 手动开启名称为“武吕蒙”的扩展，重启游戏并新开一局。
3. 启用该武将包，选择武吕蒙测试。初始状态应为吴、男、3/6，不是6/6。
4. 若在编辑器另建过同名技能测试版本，请停用该旧测试扩展，避免重复代码干扰。

包根目录是extension.js、info.json、bjgy_wulvmeng.jpg、本说明和LICENSE。角色ID为bjgy_wulvmeng，原画路径为ext:武吕蒙/bjgy_wulvmeng.jpg，扩展名称与路径一致。

## 技能

**制己**：每回合结束时，若本回合你未使用过伤害牌，你可以回复一点体力，然后获得一张点数为6的牌，且本局游戏手牌上限+1。

**复荆**：锁定技，你使用牌时，若你的手牌上限大于体力值且此牌点数：1.小于你的手牌上限，此牌不能被响应，且此牌造成伤害后你观看受伤角色的手牌并获得其中一张红桃牌；2.等于你的手牌上限，令目标角色失去或回复一点体力；3.大于你的手牌上限，你摸一张牌，若你的手牌上限大于6，则改为手牌上限-1并摸两张牌。

**克贤**：限定技，出牌阶段，你可以令自己本局游戏手牌上限始终为六。若你因此手牌上限减少，则你摸本次减少数张牌，这些牌点数均视为6，然后本回合你使用牌无距离和次数限制。

## 已确认结算

- 制己在每名角色的实际回合结束时均可发动，包括其他角色。回复后优先从牌堆全部当前6点牌中随机获得一张，没有才找弃牌堆。满血不能回复、两堆找不到6点牌，都不妨碍后续上限+1。
- 制己只检查使用过伤害牌，不要求造成过伤害；虚拟伤害牌也计入，单纯打出不计入。同一实际回合内的额外出牌阶段继续累计；新实际回合重新记录。
- 复荆使用牌时记录当时的当前手牌上限、实际体力和牌点数；无点数按0比较，所有分支按这次记录固定，之后的变化不让同一张牌换分支。
- 复荆第一项包括使用或打出响应、无懈可击的封锁。每次属于该牌的实际伤害事件结算一次，不按伤害点数乘算；传导伤害及决斗反伤也按实际归因处理，不限最初目标，不把附带技能仅携带相同card的伤害算进去。
- 观看手牌是私下观看，不公开展示；没有红桃也能查看，只有可被获得的红桃才能取得。若受伤者是吕蒙自己，照常观看，但不制造自己获得自己已有手牌的事件。
- 复荆第二项对每名目标分别结算一次，包含自己和额外目标；由武吕蒙分别决定令其失去或回复1点体力。满血只能失去；没有目标则无此项额外效果。
- 复荆第三项判断使用时记录的上限。例如上限7时使用8点牌，先减为6，仍摸两张；下一张牌重新按当前6判断。
- 克贤发动前上限8，固定6并补偿摸2；上限3也能发动，直接变6但不补偿摸牌。无论有无补偿，本实际回合均获无距离、无次数限制，且不计入次数；禁止用牌等其他合法性限制仍然生效。
- 克贤固定的是本局最终手牌上限。体力、制己增量、复荆减量及其他通常增减不再改变最终6。固定后使用大于6点的牌，复荆第三项只摸1张，不再减上限摸2张；仍须满足手牌上限大于实际体力的前置条件。
- 补偿摸牌若被其他效果增减，实际因此摸到的牌均永久改为实体6点；在获得反应中立即使用时就已是6点。反应技能另一次独立摸牌或获得的牌不混入这次补偿。
- 这些实体牌离手、转交其他角色、装备、进入弃牌堆或回到牌堆后仍保留6点，不是回合结束就消失的标记。牌原本的其他标记不因改点被清除。
- 本局上限增量、固定6的既有永久效果不因失去原技能而撤销。本回合畅用精确绑定实际回合，包含该回合的额外出牌阶段，回合结束或中途取消时结束；不会带入下个实际回合。

## 建议测试

先测试初始3/6和制己在别人回合结束回复、检索、增上限。分别使用低于、等于、高于当前上限的牌；多目标牌可用来验证每个目标分别失去或回复体力。低点伤害牌测试无懈、闪和私看红桃；高上限时使用高点牌确认减限摸2。

克贤可分别在上限低于6、等于6、高于6时测试，检查本回合不计次、下回合恢复次数限制；把补偿牌交给别人或弃掉再取得，确认仍是6点。固定后再次发动制己，应继续回复与检索而最终上限保持6。
