# 谋黄忠 v0.1.0 测试版

武将名：谋·黄忠；势力：蜀；性别：男；体力/体力上限：5/5。

技能设计：辟境归元。代码实现、调试与打包：OpenAI Codex（GPT）协助。原画：GPT生成，由设计者提供。

## 导入

1. 若已启用旧版谋黄忠，请先停用旧版所在扩展，避免选到旧武将。本包使用独立内部ID，不覆盖其他武将。
2. 在无名杀扩展管理中直接导入本ZIP，手动开启“谋黄忠”，完全退出后重新启动游戏。
3. 选择“谋·黄忠”。无需在武将编辑器中新建扩展，无需给名称添加“自制”。

## 烈镝

锁定技，你使用杀无距离限制，装备区没有牌的其他角色不能响应你使用的杀。你对装备区牌数比你多的角色造成伤害时，伤害+X，X为其当前装备区牌的花色数。

- 普通杀、属性杀均无距离限制；这不会扩大摧锋要求的实际攻击范围。
- 每次实际造成伤害时检查双方当前装备，包含技能伤害；花色沿设计者通则只计黑桃、红桃、梅花、方片。
- 铁索传导继承本次传导的起始伤害数值，再对当前受伤者重新计算烈镝。例如黄忠无装备，甲有一种花色装备、乙有两种且连环：基础1点火伤令甲受2点，传至乙时再加2点，乙受4点。
- 黄忠使用决斗被反打时，伤害来源属于对方，不会套用黄忠的烈镝增伤。

## 摧锋

你使用伤害牌指定唯一目标时，可以额外指定一名攻击范围内的其他合法角色。

你造成伤害后，可以选择一项：①摸体力值张牌，且本回合使用的下X张牌伤害+1；②摸已损体力值张牌，且使用的下X张牌无次数限制。X为这次摸牌事件实际摸到的牌数。

随后必须选择一项：①失去1点体力，并将手牌调整至体力上限张，本回合再次选择该项时，调整的目标手牌数依次减1，最低为零；②回复1点体力，若体力已满则改为摸两张牌，然后整个摧锋在本回合失效。

- 加目标与伤害后奖励均不限于自己的回合。额外角色必须在黄忠的实际攻击范围内，且满足该牌其他目标条件。
- 一次造成多点伤害只询问一次；分别对多名角色或因铁索分别造成伤害时，可分别发动。选择回复令技能失效后，该回合不再加目标或发动伤害后奖励。
- 第一类增伤额度仅在当前回合有效；第二类无次数额度跨回合保留至耗尽，使用这些牌也不计入次数。失效不收走此前已获得的额度。
- 同类额度相加，单牌增伤幅度仍为+1。例如两次各获得三张增伤额度，结果为后六张牌各+1。两类额度可并存，一张牌可以同时消耗两类各一次。
- 下X张按使用牌计，非伤害牌也消耗；打出牌不消耗。本次伤害后新得到的额度不追溯已经使用的当前牌。已带增伤的牌后来增加的目标仍享有加伤，铁索继承该牌的伤害而不重复摧锋同一份+1；烈镝对传导另行判断。
- 摸零张的选项允许选择，随后仍须二选一。X不计马良自书等另一次摸牌，只计这一次draw事件实际获得的牌。
- 调整手牌依次为体力上限、上限减1、上限减2……；先完成失去体力及濒死救援，再调整。不足摸差额，过多自行弃置手牌。回合结束后递减重新计算。
- 这里“本回合”指当前正在进行的回合，无论其属于谁；额外回合单独计算，已结束回合的临时增伤/失效/递减不会带到以后。
