# 谋赵云 v0.1.2 修复测试版

无名杀1.11.6武将扩展，蜀势力、男性、4/4体力。扩展名称为「谋赵云」，导入时不用新建或改名。

技能设计：辟境归元。代码实现与打包：OpenAI Codex（GPT）协助。原画：设计者提供的GPT生成图。

## 本次修复

无懈可击改用本体同类技能的专用静态响应入口：在锦囊或延时锦囊结算时选择「空营·无懈」，不需要实体手牌。它与基本牌空营共享智慑、孤拒删名及成长，受原有用牌限制影响。

修复空营使用酒等牌结算后，智慑调用不存在的canDiscard接口导致的报错。智慑和孤拒均使用本体实际的可弃牌统计，包含手牌、装备与判定区并遵守禁弃效果。扩展名与角色ID保持一致，导入时覆盖旧版「谋赵云」。

## 导入

1. 在无名杀扩展管理中选择「导入扩展」，选择本ZIP，无需解压。
2. 导入后手动开启「谋赵云」，重启游戏。
3. 若曾在武将编辑器测试过同名旧技能，请移除那份测试定义，避免重复角色或技能冲突。

不依赖千幻聆音、皮肤切换或其他第三方扩展。本包未包含配音。

## 技能与结算

**空营**：你手中没有伤害牌时，你可以视为使用一张基本牌或「无懈可击」。仅支持使用，不支持打出。可选属性杀，遵守当前用牌窗口、目标和通常次数限制。

**智慑**：每回合每项限一次，每个选项执行后数值改为1，其余选项数值+1，每项数值至多为3。发动空营的牌完整结算后选择一项：①弃置任意名角色区域内共计N张牌；②令任意名角色各摸N张牌；③失去N点体力并分配总计N点伤害，若没有目标因此进入过濒死状态，你弃置N张牌且该项本轮失效。初始N均为1，数值跨回合保留。只要至少一名目标因本次分配伤害进入过濒死即成功，被救回也算；支付体力导致的濒死不算。

**孤拒**：锁定技，其他角色无法令你回复体力。空营所用牌名若本回合此前已通过空营使用过，将其从空营候选永久删除，本次牌正常结算。每删除一个牌名，本局所有摸牌数+1、出牌阶段杀次数+1、手牌上限−1，逐层累加。实体牌仍可使用，普通杀及属性杀共用「杀」牌名。自己的桃、酒或技能回复仍可生效，回复来源按引擎实际事件判定。

弃牌阶段结束时，可以按本次超限规则实际弃牌数N，视为对至多N名合法角色使用一张伤害基本牌或普通锦囊牌，无距离和次数限制且不计次。群体牌只对选定目标结算，单目标牌可以多选；其他合法条件保留。整牌结算后，对每名因此实际受伤的不同角色各弃置一张牌，包含铁索传导和决斗反伤自身。其他技能成本弃牌不计入N。闪电不按本设计的伤害牌处理。
