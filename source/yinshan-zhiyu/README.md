# 隐山之玉

版本1.0.0。面向无名杀1.11.6的四武将整合扩展，一个ZIP即可直接导入。

| 武将 | 势力 | 性别 | 初始体力／上限 | 初始技能 |
|---|---|---|---|---|
| 郑以 | 群 | 女 | 3／3 | 勘文、注典、辨书、守藏 |
| 孙伊 | 吴 | 女 | 4／4 | 占卦、绍翊 |
| 诸葛仪 | 蜀 | 女 | 3／3 | 行枢、承图 |
| 钟忆 | 魏 | 女 | 4／4 | 衡策、仿书、会仪 |

技能与武将设计：辟境归元。代码实现、验证与整合打包：OpenAI Codex协助。原画由GPT绘制、设计者提供，沿用四个单将包的原始JPEG文件。

## 导入与启用

1. 在无名杀扩展菜单直接导入本ZIP，不解压，也不需要在编辑器中新建扩展。
2. 关闭“郑以”“孙伊”“诸葛仪”“钟忆”四个单将扩展，以及包含同角色的旧“自创隐山”扩展；若编辑器中已有同ID测试技能，请先删除重复定义。
3. 手动开启“隐山之玉”，完全退出并重新启动游戏，再在武将包中启用“隐山之玉”。

角色与技能ID沿用单将版本。关闭重复扩展并重启可避免重复加载；原有单将ZIP无需删除。

## 内容

包含郑以、孙伊、诸葛仪、钟忆四名可选武将、11项初始技能，以及会仪觉醒后的衍生技玄阵。完整武将信息、技能和结算说明见《武将说明.md》。

诸葛仪采用行枢“亮出牌未被获得时弃置”的版本。钟忆保留觉醒前后两张原画，会仪觉醒后自动切换形态，无需皮肤扩展。五张立绘统一指向“隐山之玉”目录，不依赖单将扩展。

## 文件结构

ZIP根目录包含10个文件：extension.js、info.json、五张JPEG原画、README.md、武将说明.md、LICENSE。只有一个扩展入口，不包含单将ZIP或外层文件夹。

## 验证范围

面向本机无名杀1.11.6进行扩展加载、四将共同注册与关键结算的适配测试。自动验证不能替代真实客户端合包对局，仍需实际游戏测试反馈。
