# 武张辽 v0.1.0 测试版

无名杀1.11.6单机扩展。扩展和武将均名为“武张辽”，魏势力、男性、体力/体力上限4/4。

技能与武将设计：辟境归元；代码实现、验证与打包：OpenAI Codex（GPT）协助；原画：设计者提供的GPT生成图。以设计文档和会话最终确认的结算为准。

## 导入

在扩展管理中直接导入本ZIP，手动开启“武张辽”，完全退出并重启游戏，再新开一局。无需在编辑器中新建或改名。本包不依赖皮肤或其他第三方扩展。

ZIP根目录包含extension.js、info.json、bjgy_wuzhangliao.jpg、README.md和LICENSE。立绘引用为`ext:武张辽/bjgy_wuzhangliao.jpg`，原画只转换为真正JPEG，不裁剪、不缩放，原始PNG保持不变。

## 威袭

你使用手牌指定其他角色为目标时，每张牌限一次，可以废除自己的一个可用装备栏，然后获得X名不同其他角色各一张手牌。若本次使用牌的点数为4，改为废除本牌一名其他目标的一个可用装备栏，持续至其下一个实际回合结束；仍执行获得手牌的效果。

- 由武张辽选择废除栏位及取牌对象。直接使用实体手牌或以本人手牌为材料的转化均可；纯虚拟无手牌材料不能发动。
- X在废栏及其引发的相关触发全部结算后、开始拿牌前固定，等于所有存活在场角色的实际废栏总数，至多4，包括武张辽本人。同类扩展栏分别计算，合并坐骑按本体视为一个栏，只计常规五类装备栏。
- 拿牌对象不限于本牌目标，从有手牌的不同其他角色中选择X人；人数不足则全部选择，每人获得一张。后续逐人获得时不重算X。
- 4点分支不要求武张辽自己仍有可用装备栏，但本牌必须有可废栏的其他目标。废栏未实际执行则不拿牌；实际废除后被其他效果立即恢复，不撤销已支付的本次效果。
- 临时废栏期限包含额外回合；背面翻回正面而直接跳过的回合不消耗期限。临时份额提前恢复便取消其旧到期恢复，同类型临时与永久废栏并存时优先恢复临时份额，之后重新废除的栏不会被旧期限误恢复。
- 已产生的临时恢复义务独立于来源失技或阵亡；目标死亡期间不计入全场废栏总数，没有实际执行到相应回合时不凭空消耗期限。

## 整锋

锁定技，若你有被废除的装备栏，你的手牌点数视为你的实际废栏数。你使用的4点牌本身对其他角色造成实际伤害，或该牌本身效果获得其他角色的牌后，你摸一张牌，然后恢复自己的一个废栏。

- 本次用牌在使用时固定点数。已有三个废栏时以3点使用，再发动威袭废第四栏，本张牌仍为3；以4点使用后恢复栏位，本张牌仍为4。
- 单张手牌转化继承整锋修正后的点数；多材料转化按转化本身规则处理，通常无点数，不将两个4点相加或自动改为4。
- 每次实际伤害事件、每次符合条件的获得牌事件各发动一次，不按伤害点数或获得张数倍增。同张4点牌对多个目标或额外结算分别造成伤害，可以分别触发；铁索传导仍按原牌来源判断。
- 获得牌必须由该4点牌本身效果产生，例如顺手牵羊获得手牌、装备或判定牌；威袭及其他技能取得牌均不触发，不能借同一用牌的祖先事件混算。伤害也只认原牌本身的实际正伤害。
- 先摸牌，再由你选择恢复自己的一个废栏。没有废栏仍摸一张，只跳过恢复；摸牌后已离场则不再打开恢复选择。

## 震贤

限定技，出牌阶段，你可以令发动时所有有废栏的其他角色的普通武将技能失效至本回合结束。本回合你每击杀一名角色后，可以永久获得其阵亡时实际拥有、且你尚未拥有的一项可获得武将技能。

- 封印包含锁定技，保留持恒技、charlotte独立机制和装备授予效果；华章不是技能，照常生效。
- 封印名单在发动时确定，后来恢复全部栏位仍封到本回合结束，后来才被废栏的人不追加。没有封印目标时仍可发动以取得本回合击杀效果，限定次数照常消耗。
- 夺技对象不限被封印者，每次击杀均可选择，也可放弃；所得技能永久保留、可以累积，不在下一次取得时替换旧技能。
- 按阵亡时当前拥有的技能筛选，后来获得的可以选择，已经失去的不能选择，暂时失效仍算拥有。死亡清理前保存技能快照，避免后来获得的临时技能被死亡清理移除后漏算。
- 排除装备技能、charlotte、主公技、限定技、觉醒技、隐匿技、使命技及其他不能正常获得的特殊技能；本人已有技能不重复获得。没有符合技能则跳过。
- 封印与击杀期间效果独立于震贤主技能，失去主技能不会提前撤销。当前实际回合正常结束或中止都会清理期间效果，已获得技能和限定已使用状态保留；已死亡或离场的受益者不打开选技界面。
