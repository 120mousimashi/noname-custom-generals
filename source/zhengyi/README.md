# 郑以

无名杀1.11.6单机测试扩展，版本0.1.0。群势力，女性，初始体力3，体力上限3。

技能设计：辟境归元。代码实现与打包：OpenAI Codex协助。原画由设计者提供，使用本次提供的新原画；仅转换图片格式，不裁切、缩放或重绘。

## 导入

在无名杀的扩展菜单选择导入扩展，选择本ZIP。导入后手动开启“郑以”并重启游戏，在武将包中启用本扩展。

无需新建扩展。扩展名是“郑以”，立绘路径为 `ext:郑以/bjgy_zhengyi.jpg`。如果编辑器里有重复的同ID测试技能，请删除旧定义，避免旧代码抢先加载。本包使用独立命名空间，不需要使用旧的“自创隐山”嵌套压缩包。

## 技能

**勘文**：转换技，出牌阶段，你可以观看一名角色的手牌，然后弃置其区域内所有，阳：红色牌，若你弃置了自己的牌你获得任意张牌名字数共计为X的牌，否则该技能本回合失效；阴：黑色牌，若你弃置了自己的牌你视为使用一张牌名字数至多为X的基本牌或普通锦囊牌（无距离和次数限制且每回合每种牌名限一次），否则该技能本回合失效（X为该技能本阶段的发动次数且达到5时该技能本阶段失效）。

**注典**：锁定技，你获得牌时，若手中黑色牌更多，你使用的下一张牌无距离和次数限制；若手中的红色牌更多，你使用的下一张牌不能被响应。

**辨书**：出牌阶段每名角色限一次，你可以令一名角色展示一张手牌，然后你可以摸一张牌并展示一张手牌，若与其被展示的牌颜色不同，你可以令自己或该角色武将牌上的转换技视为未发动过且在不发动的情况下改变阴阳状态。

**守藏**：你使用或打出牌时，可令手中同牌名牌不计入手牌上限且不能被弃置；一名角色回合结束时，若其手牌数大于其手牌上限，你可以令其摸两张牌；你阵亡时，可令一名其他角色获得该技能。

## 本次定稿结算

### 勘文

- 默认阳状态。每个实际出牌阶段分别统计X，从1开始；第五次完整结算后本阶段失效，不会出现第六次。此规则采用本次对话定稿，输入文档残留的“大于5”按“达到5”处理。
- 可选择自己，可以选择没有手牌的角色；弃牌范围包括手牌、装备区、判定区，遵守不可弃置效果。只有实际弃掉至少一张自己的牌才能获得后续效果；否则本回合失效。已发动的这次仍切换阴阳。
- 阳面只选择数字，不能指定牌名。以X为预算，每次强制从1至剩余预算选n，先从牌堆符合n字的牌中随机获得一张，牌堆没有则从弃牌堆随机获得；然后扣n，有剩余继续。两处都找不到牌也扣额度。
- 例如X为4，先选1，随机获一字牌，余3；再选3，随机获三字牌，预算清零后结束。
- 阴面必须选择并使用一张合法的基本牌或普通锦囊，无合法选项时无事发生。虚拟牌无色无点数，无距离和次数限制且不计次。普通杀、属性杀均按“杀”一字，共用本回合一次。真正成功使用才占牌名限制。
- 同回合额外出牌阶段重新统计X，但本回合失效和本回合已用牌名仍保留。

### 注典

- 每次实际获得牌后，以当时全部手牌的红黑数量比较，回合外也能触发。
- 两种效果可以共存，同种不叠加次数；数量相等不新增，也不清除原有效果。跨回合保留到下一次使用牌，打出牌不消耗。
- 下一张使用的牌同时消耗当时已有的效果；这张牌结算中新获得的效果保留给之后使用的牌。无距离和次数限制同时不计次，“不能被响应”覆盖其他角色的无懈响应。

### 辨书

- 第一张展示牌由目标自己选择，目标可以是本人。后续本人可以拒绝；确认后摸一张，再自选展示一张当前手牌，可以选刚摸到的牌。
- 两张展示牌须分别为红色、黑色。颜色不同后仍可拒绝改变转换技，或在自己与原目标中选择一人。
- 处理该人武将牌上当前持有的全部转换技，包括后来获得的技能；不处理已经失去的技能和装备技能。
- 重置次数与解除失效分开。勘文只清X，不解除本阶段/本回合失效，不清阴面已用牌名。各转换技通过原生接口转换，不执行技能效果，不视为发动。
- 已适配本机原生计次，以及贞良、审时、叠嶂、盟谋、游龙、游凤、族联诛、权谋的特定次数记录，保留永久成长、效果、已用牌名和封印状态。原技能已有永久形态改变时，遵守其原生转换回调。第三方扩展自定义的特殊次数存储仍需按其实现测试适配。

### 守藏

- 可选发动，只保护发动时手中剩余的全部同名牌。普通杀与属性杀共用“杀”的牌名。后续获得的同名牌不自动受保护。
- 保护持续到牌离开手牌，离手即清，再获得不自动恢复。保护期间不计入手牌上限，不能被自己或他人弃置；可以正常使用、打出、交给、被获得、重铸。
- 回合末比较实际全部手牌数（含受保护牌）与完整修正后的手牌上限，符合时可令该回合角色摸两张。多名守藏持有人分别选择、实时判断。
- 阵亡者可以拒绝传承，或令一名未拥有守藏的其他角色获得完整技能。继承者将来阵亡时可继续传承；不会额外要求接收者确认。
