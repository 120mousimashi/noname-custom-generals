# 玄谍既白 v1.0.0

包含隐蕃、郭脩、马茂、郭模四名武将的独立整合扩展。四人的完整技能与原画在同一个扩展内，可直接导入本ZIP；不是四个独立ZIP的集合。

技能设计：辟境归元。代码实现、验证与整合：OpenAI Codex协助。原画由GPT绘制、设计者提供。

## 导入与启用

1. 在无名杀扩展菜单选择导入扩展，选中本ZIP直接导入。
2. 手动开启“玄谍既白”。停用原来的“隐蕃”“郭脩”“马茂”“郭模”四个独立扩展，避免同名武将、技能及全局观察规则重复加载；四个原ZIP可以继续保留。
3. 如果编辑器或“自制”扩展里有这些武将的同名测试技能，也先移除或停用测试版本。
4. 完整退出并重新启动游戏，启用“玄谍既白”武将包，再选择这四名武将测试。

本包面向无名杀1.11.6及用户现有桌面启动器的单机环境。安装后不依赖四个独立扩展。原画统一使用extension/玄谍既白/路径；仍叫隐蕃、郭脩、马茂、郭模，不给人物名称添加系列前缀。

## 文件

ZIP根目录直接包含extension.js、info.json、四张武将JPEG原画、本说明、武将说明、测试报告和LICENSE。extension.js只有一个扩展导入入口，内部已整合全部技能及辅助规则。

## 验证与反馈

已进行来源字节一致性、同名表项冲突、原画路径和原生引擎混合事件检查，具体数量和范围见《测试报告.md》。检查包括四将一起加载、谊牌被过魏交换后触发构间、联逆与泄谋增伤及过魏距离效果共存、郭脩处决与响应恢复。

自动房间使用有界DOM、场景准备和最终合法人工输入，不等同于真实客户端完整对局验收。马茂匿名适配仍保留原独立包的范围：真实来源与规则状态不伪造，未知第三方自行画图、播放声音、延后回调、联机和录像未验收。四将整合后的实机结果请由设计者继续测试反馈。
