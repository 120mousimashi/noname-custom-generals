# 谋法正 v0.1.0 双形态测试版

武将名：谋·法正；势力：蜀；性别：男；体力/体力上限：3/3。

技能设计：辟境归元。代码实现、调试与打包：OpenAI Codex（GPT）协助。原画：GPT生成，由设计者提供。白旗原画对应阳状态，红旗原画对应阴状态。

## 导入与双形态

1. 若已启用旧版谋法正，请先停用旧版所在的扩展，避免选到旧武将。本包采用独立内部ID，不会覆盖其他武将。
2. 在无名杀扩展管理中直接导入本ZIP，手动开启“谋法正”，完全退出后重新启动游戏。无需在编辑器中新建扩展，也无需给扩展名加“自制”。
3. 选择“谋·法正”。游戏开始时选择阳或阴，之后每次成功发动谙谋都会转换状态并自动更换原画。
4. 原画使用本体characterSubstitute/changeSkin接口，无需千幻聆音或皮肤切换扩展。

## 谙谋

转换技，游戏开始时自选阴阳状态。有角色跳过阶段或翻面时，你可以选择一名角色，阳：令其摸X张牌并回复1点体力，然后其当前手牌中的伤害牌不计入手牌上限，其下X次使用非伤害牌结算完成后摸一张牌；阴：令其弃置X张牌，并视为使用等量张杀或决斗，该技能结算完成后，每因此受到一点伤害的角色获得一层“使用下一张牌无效”标记（X为其体力上限且至多为5）。

- 翻至背面与翻回正面均可触发。跳过准备、判定、摸牌、出牌、弃牌、结束阶段均在范围内，同一次阶段跳过只处理一次。
- 可以选择自己。X以选定角色时的体力上限为准。
- 阳状态先摸牌、回复，再标记此时手牌中的伤害牌；未来新获得的牌不自动补标。牌离开手牌后不再享有此标记。非伤害用牌的摸牌次数可以跨回合累加，例如两次X=3对应未来六次各摸一张。
- 阴状态由目标自行选择手牌或装备牌弃置；不足则尽量弃，以实际弃置数决定视为使用数。逐张选择普通杀或决斗，可以混选，由其选择合法目标，无距离和次数限制；存在合法选择时须继续使用。
- 这些牌造成的实际伤害包括铁索传导与决斗反伤。每点伤害对应一层标记，整次谙谋结算完后统一给予。之后每使用一张牌移去一层并使整张牌无效；层数可叠加、跨回合保留，打出牌不消耗。

## 知变

每回合每项限一次。有角色的体力值发生变化时，你可以观看牌堆顶六张牌并选择一项：

1. 令一名角色获得其中所有红桃牌，然后将任意张其未获得的牌放到牌堆底；其下一个实际开始的回合中，第X个阶段开始时跳过该阶段。
2. 令一名角色获得其中所有伤害牌；其下一个实际开始的回合中，第X个阶段开始时，先执行一个相同阶段。
3. 令一名角色获得这些牌并翻面，然后本选项失效，直到该角色回合结束时其自获得这些牌起累计使用了等量张牌，或该角色阵亡。

X为本次实际获得的牌数。三项均可另选任意在场角色，包括自己。

- 体力实际增加或减少才触发；仅体力上限改变或护甲抵消至体力未变不触发。一次改变多点体力仍是一次时机。
- 第一项留下的牌堆顶余牌保持原顺序；可以为置底牌安排顺序。第二项余牌按原顺序放回牌堆顶。没有红桃/伤害牌仍可选择对应项，X=0时没有阶段效果。
- 阶段依实际进行顺序编号，额外阶段占一个序号，已被其他效果跳过的阶段不占。例如兵粮跳过摸牌后，出牌为第3阶段；潘濬在正常出牌后增加的出牌阶段为第5阶段。
- 同一序号同时有增加与跳过时，先执行额外阶段，再跳过原阶段，两条效果当次同时消耗。知变产生的额外阶段也参与编号，已消耗效果不会重复发动。
- 普通回合、额外回合均计入“下一个回合”；翻面而跳过整个回合不消耗等待。所有记录仅在下一个真正开始的回合生效，该回合结束后未命中的记录也清除。
- 第三项的累计包括跨回合、回合外及不计次的使用牌，不包括打出。达到张数后仍等到该角色回合结束才恢复选项；其阵亡立即恢复。翻面无论当前正反都会翻转。

## 测试范围

目标本体：无名杀1.11.6。此包是重写后的首个测试版，需由设计者实际对局反馈。交付前进行结算回归、本机原生事件编译器验证，以及ZIP结构、图片、字节读回校验；这些检查不等同于真实对局、联机或录像回放验证。

建议优先测试：开局阴阳选择和换图；翻回正面触发谙谋；伤害多点/传导/决斗反伤的无效层；兵粮跳过与潘濬额外阶段的知变编号；知变同序号增加和跳过；第三项使用牌累计及目标阵亡解锁。
