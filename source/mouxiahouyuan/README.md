# 谋夏侯渊 v0.1.0 测试版

武将：谋夏侯渊；势力：魏；性别：男；体力/体力上限：4/4。

技能设计：辟境归元。代码实现、调试与打包：OpenAI Codex（GPT）协助。原画：GPT生成，由设计者提供。

## 导入

在无名杀扩展管理中直接导入本ZIP，手动开启“谋夏侯渊”，完全退出后重新启动游戏。选择“谋夏侯渊”即可。无需在武将编辑器新建扩展，无需加“自制”前缀。若另有旧版谋夏侯渊，请先停用旧版所在扩展，避免选到旧角色；本包使用独立内部ID，不覆盖其他武将。

## 分援

回合开始时，你可以选择至多体力上限个不同的常规阶段，然后令任意名存活角色获得共计等量个“驰”标记，且本回合你跳过这些阶段各一次。若有角色本次获得不少于两个“驰”，本回合结束时你翻面一次。

拥有“驰”的角色需要使用或打出杀时，可以移去一枚“驰”，视为使用或打出一张普通杀；以此法使用的杀无距离和次数限制且不计次。

- 六种可选阶段为准备、判定、摸牌、出牌、弃牌、结束；不选择就是取消。选择四个阶段就分配共四枚，可以集中给一人，也可以分给多人，觉醒前可以给自己。
- 可以选择已被其他效果确定跳过的阶段。每种名称只跳一次，本回合后来新增的同名阶段仍可进行，除非有其他效果令其跳过；未执行到的本次跳过不会泄漏到下一回合。
- 翻面条件只看本次单人获发数量，已有标记不计入，本次获两枚后提前用光也照样翻面。多人各获两枚仍只翻面一次。跳过结束阶段不免除回合末翻面，翻面为正反状态切换。
- “驰”无数量上限、无期限，独立保留至消费。来源阵亡或分援失效不撤销持有者使用权，觉醒不追收之前发给别人的标记。
- 可以在正常出牌、借刀等需要使用杀的场景使用，也可在决斗、南蛮等需要打出杀时使用。取消选择不扣标记；正式使用或打出时扣一枚。其他禁用牌、禁响应、目标限制仍须遵守；手里的其他杀不会因持有“驰”而自动无限。

## 筑栏

锁定技，你背面朝上时不能响应其他角色使用的杀。你成为其他角色使用的伤害牌的唯一目标时，若你在其实际攻击范围内，你复原武将牌。

当你翻面或复原武将牌时，选择一项令一名角色执行，选定后永久删除该项，并令其他未删除选项的数值+1：

1. 随机使用牌堆、弃牌堆中的1张合法装备牌。
2. 自行弃置1张手牌或装备牌。
3. 失去1点体力。

- 复原指翻至正面并解除横置。本来正面且未横置时不触发筑栏。一次完整复原只触发一次；单纯解除连环不当作完整复原。
- 普通翻面两个方向都触发。先选定并删除选项、增加其他数值，再执行效果；完全无法执行也可以选择，数量不足就尽量执行，不撤销删除或数值增加。
- 装备由被选角色真正使用，可以替换原装备，会产生使用装备牌的相应时机。装备逐张随机选取，同一次效果不重复选同一张实体牌。没有合法装备就停止本项使用。
- 三项数值依删除顺序变化为初始各1、剩余各2、最后一项3；删除永久有效，不在回合末恢复。

## 孤栅

觉醒技，每名角色的回合结束时，若筑栏三项均已删除，你复原武将牌，然后本局游戏分援只能令你获得“驰”，并获得愍锋。只觉醒一次，没有额外减体力上限。

同一回合末按“分援翻面→结算筑栏→检查孤栅”处理；若这次翻面恰好删掉最后一项，可以当次觉醒，最后由孤栅复原。觉醒只限制以后新分配的接收者，其他角色原有的“驰”继续可用。

## 衍生技：愍锋

限定技，出牌阶段，你可以摸体力上限张牌，然后失去结算当时所有体力。本阶段你使用无次数限制或不计次的杀时，此牌伤害+1。

- 先摸牌，再按当时实际体力失去全部体力，会正常进入濒死。获救后，本次出牌阶段的增伤效果继续。
- 驰、诸葛连弩、咆哮及其他技能赋予的不计次杀都认可；龙吟在杀使用到较晚时才赋予的不计次也认可。仅增加有限的一次或几次杀使用次数不算无限制。
- 同一张符合条件的杀只加一次，后来额外指定的目标也享有该牌增伤；打出的杀不触发。效果仅限本次出牌阶段，不带到额外或以后的出牌阶段。限定技不能再次发动。
