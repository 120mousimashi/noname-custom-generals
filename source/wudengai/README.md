# 武邓艾

v0.1.0 测试版，适配无名杀 1.11.6。魏势力，男性，初始体力4，体力上限4。

技能设计：辟境归元。代码实现、验证和打包：OpenAI Codex协助。原画：设计者提供的GPT生成图。

## 导入

1. 在无名杀的扩展管理中选择导入扩展，选择本ZIP，无需解压，也无需新建扩展。
2. 导入后手动开启“武邓艾”，重启游戏，再开一局测试。
3. 武将包名称和图片目录均为“武邓艾”。请勿自行给扩展名称添加“自制”等前缀，否则图片路径可能失效。
4. 若此前在编辑器创建过相同内部ID的测试技能，请先移除旧测试副本，避免重名覆盖。其他武将扩展不必删除。

ZIP根目录直接包含extension.js、info.json、bjgy_wudengai.jpg、README.md、LICENSE，导入器无需再打开内层ZIP。未包含语音文件。

## 技能

**开畴**：锁定技，你失去基本牌后，本轮你与其他角色的距离-1，然后你视为对所有与你距离在1以内的角色使用一张“五谷丰登”；其他角色因你使用的“五谷丰登”获得牌时，须交给你一张牌；你因“五谷丰登”获得的牌不计入手牌上限；若本轮场上所有角色均因“五谷丰登”获得过牌时，本轮有角色使用“五谷丰登”时改为将亮出的牌放到你的武将牌上称为“畴”。

**逾险**：锁定技，你使用点数为9的手牌结算完成后弃置一张“畴”，然后视为使用一张不计次的“杀”或“顺手牵羊”；你手中不计入手牌上限的牌点数视为9。

**辟贤**：限定技，出牌阶段，若你与所有角色的距离均不大于1且你拥有场上角色数两倍的“畴”，你可以弃置所有“畴”，然后视为使用其中每种牌名的基本牌和普通锦囊牌各一张，这些牌结算期间每有角色受到一点伤害或失去一张牌，你可以摸一张牌或给一张手牌永久增加以下一种此牌没有的效果：1.你使用时额外结算一次；2.你使用时不能被响应；3.你使用时无距离和次数限制。

## 结算约定

- 开畴一次失牌事件只触发一次；失去或弃置“畴”不触发。距离只减少自己计算至其他角色的距离，本轮累积，下轮重置。五谷目标包含自己。
- 其他角色直接从你所用五谷获得牌后，从自己的手牌、装备中交给你一张，可以交刚获得的那张。通过其他技能转交、回馈所得不算直接从五谷获得。
- 你直接从任何角色所用五谷获得的牌，获得后立刻不计手牌上限，直到失去该牌；转交后不保留免手限。
- 得牌覆盖记录按本轮所有五谷计算。完成覆盖的当前五谷正常结算，随后本轮新使用的五谷才将实际亮牌全部转为畴，其他人不再选牌。原生五谷的亮牌数量修改仍生效。
- 逾险按使用时的点数与手牌来源判断，支持手牌转化；无畴则不执行。有畴先强制弃一张，再选择合法的杀或顺手牵羊，不计次但保留距离限制。无合法目标时弃畴后不再使用牌。
- 其他来源的不计手牌上限效果也可使手牌视为9点。单张手牌转化继承该效果，多素材转化不会因此自动拥有9点。
- 辟贤要求畴数至少为当前存活角色数的两倍，且自己到所有其他角色距离不大于1；发动时弃置全部畴。只印基本牌和普通锦囊，每种牌名一次；同名杀可选弃置素材里已有的属性。顺序由自己选择，合法牌必须使用，无合法使用条件的牌跳过。
- 辟贤印牌均无距离、次数限制且不计次。初始弃畴费用及其附带结算不产生奖励；之后整段印牌及全部嵌套结算期间，全场每点实际伤害、每张实际失牌各提供一次可取消的奖励。响应、交给、本人失牌和附带技能结算均可计入，同一失牌不重复计算。
- 永久强化随实体牌保留，任何后来持有者使用时均可享有。每张牌每种强化仅一次，转化素材的不同强化取并集，同种不叠加。牌面以“辟贤·复结”“辟贤·直击”“辟贤·畅用”显示。
- “额外结算一次”增加整张牌的一轮结算，并非再次使用；不能重复结算的装备、延时锦囊不产生额外结算。“不能被响应”包含无懈可击。“无次数限制”同时不计入使用次数。

## 建议测试

依次检查失去多张基本牌只触发一次、五谷给牌和免手限、全员得牌后的收畴、九点转化牌触发逾险、辟贤多牌连续结算，以及强化牌转交给别人后的三个效果。若出现报错，请保留完整报错截图、当时使用的牌与双方技能。

本包经过语法、资源路径、ZIP读回及本体编译器参与的自动化验证。UI选择和部分实体移动使用受控测试替身；尚未在真实对局、联网或录像回放中全面验证。
