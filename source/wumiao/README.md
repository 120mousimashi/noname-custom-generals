## 导入与启用

1. 在无名杀扩展菜单导入本ZIP。
2. 关闭对应的八个单将扩展，其中武段颎旧扩展名是“自制武段颎”；若编辑器已有相同ID的测试技能，也请删除重复定义。
3. 手动开启“自制武庙”，重启游戏，再在武将包中启用“自制武庙”。

角色和技能ID沿用单将版本。关闭重复扩展并重启，可以避免同ID定义和全局辅助规则重复加载。原有单将ZIP无需删除。

无需新建扩展，也不要改动扩展名或图片文件名。八张立绘统一使用 `ext:自制武庙/角色ID.jpg`，不依赖单将扩展目录。

## 内容与版本

本包包含八名可选武将、24项主技能、原有辅助规则、周瑜两项永久改写及其动态技能说明。完整武将信息和技能描述见同目录《武将说明.md》。

来源为武段颎v1.0.0，以及武张辽、武周瑜、武吕蒙、武邓艾、武王濬、武羊祜、武杜预各自已制作的v0.1.0包。保持原武将属性、角色ID和技能主体；本次整合统一资源路径、合并包注册，并修正张辽辅助规则的启动时序，使同步开局安装完整完成。

所有原画原字节保留。武吕蒙为3／6、武羊祜为3／3、武段颎为5／5，未统一为四体力。
