# 翰墨凝威70篇结算定稿

本文件记录已确认的结算，优先于篇目简写产生的歧义。1.1.0收录威曹丕（魏、男、4体力，评文、品藻）、威曹植（魏、男、3体力，高才、华藻）、威曹操（魏、男、4体力，横槊、建安）。其他作者的华章也全部收录。

## 威曹操个人技能

- 横槊：出牌阶段主动限三次，可分开使用且重复选择同一可拼点其他角色；平局仍耗一次，但不执行赢家效果，也不触发建安。
- 拼点和相关触发（包括建安书写）全部完成，再读取赢家当前手牌数与其当前体力值确定一次分支。曹操决定是否执行，执行后赢家不能拒绝，由赢家选择属性及合法目标。
- 大于：无实体酒，可超过通常酒上限，不计酒次数；等于：赢家视为使用一张无实体决斗，指定一至两名合法目标；小于：赢家视为使用一种合法属性的无实体杀，仅免距离、不免杀次数。
- 杀分支必须实际使用杀才摸手牌至体力上限，照原猘锋在使用【杀】时立即补牌，早于目标结算和伤害，不要求命中。因次数/禁用/无合法目标等不能使用，不补牌。
- 建安：锁定，自己任何来源的实际拼点胜利都书写华章，作为被拼点方获胜也计。一对多逐组获胜每组各写一次；共同拼点仅最终唯一赢家写一次。每个实际胜利结果只结算一次，不重复计父事件汇总。
- 建安生效时外来华章无上限；失效/失去后保留所有已有篇目并正常发动，新增普通外来篇按三篇上限，自作和独立免额不受影响；恢复后重新不限。此特权不附着于篇目，转交/继承按接收者当前容量。

## 威曹植个人技能

- 高才：自己每次实际使用牌记录一次牌名，可重复，跨回合保留。所记录牌名总字数不小于8时先全部清空，再摸2，不保留超出部分；单次使用不因多目标或额外结算重复记录。虚拟使用及华藻印牌计入，打出不计。
- 华藻：出牌阶段限一次，至少一张可弃手牌，按所选牌名字数排序检验等差，1/2张及公差0均合法；最终确认前可取消，不消耗次数。牌名与类别按弃前有效状态快照，数量与类别门槛以实际弃掉的牌为准。
- 顺序为弃牌→摸等量→不少于一类书写华章→不少于两类强制视为使用普通锦囊→三类视为未发动。三类递进，基本/锦囊/装备，延时锦囊归锦囊类别但不能作为印出的普通锦囊。
- 华藻的每回合每牌名一次只统计通过华藻使用的普通锦囊，不受本回合其他方式已用同名牌影响；按全回合记录，额外出牌阶段不会刷新这份牌名记录。印牌仍遵正常使用合法性，有合法选项必须选，无合法选项跳过。
- 华章库无可获得篇目时书写失败，继续后续；三类只恢复华藻阶段发动次数，不恢复本回合锦囊名。高才与印牌正常联动。“未反动过”按用户修正为“未发动过”。

## 华章公共规则

“华章”是“翰墨凝威”的专属机制，以文人作品命名。系列设计关注牌名、牌名字数等文字概念，书写的具体条件和附带效果由各武将技能决定。

- 华章全场唯一，包括候选预留、持有、已发动及延时结算。自作按历史作者识别，不看版本前缀；自作不限，普通外来总计最多三篇，不替换，建安生效者例外。免额作品独立计数，跟随实例转移，回库后清除。
- 书写从当前能获得的空闲篇目随机抽至多三篇，有剩余可得自作时必含至少一篇；选一持有，其余释放。普通外来满三时只能抽自作，建安生效时仍可抽外来。指定作者书写按正文直接选该作者空闲篇，并授予实例免额。
- 华章通过公共规则生效，不计入个人技能数，不依赖母书写技能、原作者存活或个人技能是否被常规封印。华章效果授予的普通个人技能仍按该技能正常机制处理。
- 主动选牌/选人未确认可以取消且不耗篇。触发式先确认，后续任意张选牌不可取消但允许零张；固定数量成本须完成。通过转化牌发动时，在最终确认后才锁定华章；取消不耗篇。
- 一般完整结算及显式延时结束后回库。武军赋、与吴质书确认即回库，后续牌独立结算；新实例可以接续触发，旧实例不能误消耗新实例。
- 典论摸完、洛神判定完、咏史取牌完、瓜赋奖励摸完、定向书写完成后母篇回库，相应牌标记或免额实例独立运行。典论标记只到本回合末；洛神、咏史、瓜赋牌标记到真正失去牌。
- 未发动华章阵亡时可交一名其他角色继承，接收者选择可容纳篇目，其余回库。结算中华章不遗传；相关目标全死亡/永久离场后终止并回库。
- 新获得华章不补触发已经发生的时点。全局用牌按实际使用顺序记录，不按结算完成顺序。
- 无次数限制与不计次数合并；未写无距离则仍有距离。未指来源的获得先检索牌堆，再弃牌堆，不够则只获得能找到的。
- “一名角色的牌”指手牌与装备；“区域内的牌”包含手牌、装备、判定。“交给”是主动给，交换也按双方主动交给；夺取不算交给，但算获得他人牌。弃置他人牌由发动者选，令他人弃由其自己选。

## 颜色、花色、点数

新默认只考虑红黑、四常规花色、整数A—K；不另提供无色、无花色、无点数或超K选项。以前明确确认的例外保留：观沧海可以记录0点，汝颍无色与无色同色，薤露的花色统计包含无花色这一第五种。名都、登楼只四常规花色。默认类别为基本、锦囊、装备，延时锦囊归锦囊。

## 已确认的重要逐篇边界

- 典论可弃一张、两张，公差0合法；所得牌兼容官方肃纲的典论标签，旧官方威曹丕技能不加给翰墨威曹丕。
- 吴质素材须本回合进入过弃牌堆且目前仍在；本人本局实际使用过的基本/锦囊含虚拟、属性杀和延时锦囊；最终合法组合强制选一个。
- 芙蓉、为曹公只能用实体手牌，允许提前被改名的牌，不允许现场转化；可以拒绝。为曹公按普通距离次数，不抄妩艳的额外豁免，只在整张牌造成过伤害后给持有者和用牌者各摸2一次。
- 秋胡统计选择所在回合之后实际发生的回合结束次数，至少1。弟仓选牌者必须至少取得一张合法牌，余牌原序回顶。短歌从其他角色区域内各取一张。
- 洛神黑判后可以停止；白马保留实际杀属性等牌属性，基础目标是伤害来源。七步统计整个阶段，包括发动前已使用的牌数，失血看本次实际主摸牌数量。
- 赠白马是两人之中下一次实伤后结算一次；名都没拿到牌无增益，仍到阶段末回。求自试可给0，插入完整额外回合后原回合继续。
- 精列到首次濒死立即解除防伤、禁疗、逐回合失血，然后可以救援。对酒满血也可选空回复。
- 荐祢衡只用开始时快照里的手牌，新得牌不能用；一张初始牌用后又回手也不重复用。拼点平局不算赢；与王朗逐对处理双方没赢者，斗鸡只有唯一最高赢。
- 盛孝只代理使用或打出牌，火攻展示不代理；代理每次都可拒绝，不终止后续询问；原目标被禁止响应不禁止代理，最终响应和伤害仍归原目标。
- 檄文用全部合法伤害牌对同一基础目标，或全部非伤害牌交指定者，余牌原序回顶。谏何进若弃不全，先弃能弃的再失1体力。
- 圆扇暗存全部he，不收判定牌。虚道整张无效但仍支付、计次、记录。核辩平局无事，下一张有无目标均消耗效果；赢家只能改合法目标，固定目标仍遵原牌。
- 咏史收转化牌实体并保持原名，无素材虚拟杀无牌可获，弃不了他人牌不妨碍取牌；所得实体牌标签提供免距不计次，不带韩龙原本免手限或不可弃。
- 琴歌两分支共用一篇，红分支可拒绝；隐士只使用不打出，无素材但仍守原牌合法性，不带纠思翻面成本。
- 吊伯夷取阵亡武将原始技能，排限定、觉醒、使命、隐藏、Charlotte、不可临时借用技；只收出牌阶段主动技，借到阶段结束，不套龙诵一次发动即失去。
- 苦雨逐角色直接执行标准闪电判定，可改判，黑桃2—9受3无来源雷伤，无实体闪电放置或转交。
- 撰征按卧龙演策：三次同一预测维度，可重复，统计全场本阶段前三次使用；无色占颜色预测位置但不命中。命中立刻摸1，三全中再选一种类型得2；不足三次在阶段末结束。
- 灵河按整局最后三次全场使用，打出不计，别人的使用打断，不额外按回合清零；第三张不受影响，之后到本回合末不能响应。
- 愍骥按上轮全场用过的普通锦囊牌名，虚拟也计；首轮上轮为空。驰射X锁定发动时攻击范围数值，后续各杀免距不计次，可中途停止。
- 赠从弟只加上限不回血，每名角色本局累计至多因此加3，跨持有者/实例共享。射鸢同一次使用对首次全部目标额外结算一次，不生成新use；用牌完成后奖励等两轮结束仅一次。
- 遂志按判定类别跨回合等待下一次相同类别使用，先回复再摸2，满血仍摸。瓜赋样本多张任选、0张回库，锁定样本字数，累计本轮实际弃牌数严格大于才奖励一次并回库；轮末未达标结束。奖励实体牌使用整张结算完摸1，持续到真正失去。
- 清虑可换0、零手牌可发动；比交换后牌堆顶与手牌红黑各自张数，未换牌原序保留，私下观看。

## 兼容与测试

根据设计者反馈，目前测试未发现问题；本版面向无名杀1.11.6单机。该反馈不代表每一篇华章和所有组合均已穷举，联机、完整重连或存档续局，以及与其他扩展的全面兼容性尚未验证。

《与曹公论盛孝章书》的代响应效果已针对1.11.6中的【杀】、【南蛮入侵】、【万箭齐发】和【决斗】作适配；第三方替换结算或特殊转化仍需实测。
